BWPConvertTTNVN
PRODUCT & TECHNICAL BRIEF
Vietnamese Number-to-Words Excel Add-in

============================================================
1. PROJECT NAME
============================================================

Product name:
BWPConvertTTNVN

Suggested internal/technical identifier:
BWPConvertTTNVN

Product type:
Microsoft Excel Add-in for converting numeric values into Vietnamese words.

Primary implementation target:
VBA + XLAM

Primary platform:
Microsoft Excel for Windows


============================================================
2. PRODUCT GOAL
============================================================

Build a lightweight, offline, open-source Microsoft Excel Add-in that allows users to convert numbers into Vietnamese words through a simple click-based workflow, similar in usability to VNTools but implemented independently.

The product must focus on simplicity, transparency, compatibility, security, and ease of use for non-technical users.

The user must NOT be required to manually type formulas in order to use the core feature.

Primary workflow:

Select source cell
→ Click "Convert Number to Words"
→ Select destination cell
→ Click "Convert"
→ Vietnamese text is written directly into the destination cell.

Example:

Input:
125,430,000

Output:
Một trăm hai mươi lăm triệu bốn trăm ba mươi nghìn đồng chẵn.


============================================================
3. TARGET USERS
============================================================

The product is designed for:

- Accountants
- Finance staff
- Administrative staff
- HR staff
- Procurement staff
- Sales staff
- Business owners
- Small and medium enterprises
- Users preparing quotations
- Users preparing receipts and payment vouchers
- Users preparing contracts
- Users working with Vietnamese accounting documents

The intended user may have no VBA, programming, or advanced Excel knowledge.


============================================================
4. PROBLEM TO SOLVE
============================================================

Many Vietnamese Excel users currently rely on tools such as:

- VNTools
- AccHelper
- Legacy macros
- Unknown-source VBA modules
- Excel formulas such as =VND(A1)

Common problems include:

- Closed or unclear source code
- Compatibility issues with newer Excel versions
- Outdated user interfaces
- Dependency on manually entered formulas
- Risk of #NAME? errors when files are opened on other computers
- Unclear security and privacy behavior
- Difficulty auditing the source code

BWPConvertTTNVN must solve these problems through:

- Open source code
- Offline operation
- Simple click-based workflow
- Static text output by default
- No external DLL dependencies
- No network requirements
- Clear and modern Excel-native UI

============================================================

The main user interaction must follow:

8. QUICK CONVERT
============================================================

Provide a Ribbon button:

Quick Convert

Workflow:

1. User selects a source cell.
2. User clicks Quick Convert.
3. The converted text is written automatically into the cell immediately to the right.

Example:

A1:
1,500,000

After Quick Convert:

B1:
Một triệu năm trăm nghìn đồng chẵn.

If the destination cell already contains data, show a confirmation dialog:

"The destination cell already contains data. Do you want to overwrite it?"

Options:

- Overwrite
- Choose another cell
- Cancel


============================================================
9. BATCH CONVERSION
============================================================

The add-in must support converting multiple rows at once.

Example:

A2 = 1,000,000
A3 = 2,000,000
A4 = 5,500,000
A5 = 10,000,000

User selects:

A2:A5

Then clicks:

Quick Convert

Expected output:

B2 = Một triệu đồng chẵn.
B3 = Hai triệu đồng chẵn.
B4 = Năm triệu năm trăm nghìn đồng chẵn.
B5 = Mười triệu đồng chẵn.

Each source row must map correctly to its corresponding destination row.


============================================================
10. OUTPUT MODES
============================================================

The add-in must support two output modes.

MODE 1 — STATIC TEXT

Default mode.

The converted result is written directly as plain text.

Example:

Một trăm triệu đồng chẵn.

Advantages:

- No dependency on the add-in after conversion
- No #NAME? error on another computer
- Safe for sharing files
- Recommended for accounting documents and contracts

MODE 2 — FORMULA

The add-in may insert a worksheet formula.

Examples:

=VNWORDS(A1)

or:

=VND(A1)

The result should update automatically when the source value changes.

Default setting:

Static Text

20. SELECTION HANDLING
============================================================

If the user selects a range such as:

A1:A100

The add-in must process the whole range.

Supported cell types may include:

- Empty
- Text
- Error
- Number

Only valid numeric cells should be converted.

After batch conversion, optionally show a summary:

Conversion completed.

Converted: 96 cells
Skipped: 4 cells


============================================================
21. LOCALE AND NUMBER FORMATTING
============================================================

The add-in must correctly handle numbers regardless of displayed separators.

Examples may include:

1000000
1,000,000
1.000.000

Do not blindly remove punctuation.

Prefer the actual numeric value stored by Excel.

The implementation must respect Excel locale behavior whenever possible.


============================================================
22. ERROR HANDLING
============================================================

The user must never see raw VBA runtime errors during normal usage.

Do not expose messages such as:

Runtime Error 13

Instead display friendly errors.

Example:

Conversion failed

The selected source cell does not contain a valid numeric value.

Errors should be caught and handled gracefully.
